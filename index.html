Website Layout Examples

For task 3 you need to provide 2 initial designs. These examples show two different layouts you could use for your designs.

Responsive horizontal navigation

2 columns horozontal navigation Responsive
  • Header across page containing page title
  • Horozontal navigation bar across page

  • Footer across the page at the bottom
